## The workflow

1. Copy the installation commands from GitHub and run them in your terminal.
2. Open Codex Plugins, search for `diff`, and select Diffusion Studio.
3. Ask Codex to create a short animated video showing the plugin's capabilities.
4. Play the preview, then open the project in Diffusion Studio to see its canvas and moving timeline.
5. Review the result and ask Codex to export your video.

The demo prompt:

> Create a short animated video showcasing this plugin's capabilities: create and edit video, add captions, preview, and export. Use kinetic typography and show me a preview.

The animated example highlights **Create → Edit → Caption → Preview → Export**. Playback continues from the same moment when the editor opens.

For setup, example prompts, updates, and troubleshooting, follow the [main guide](../README.md).

## About this demo

The GitHub, terminal, and Codex interactions are recreated for the demo. The animated example and editor capture use real Diffusion Studio output. This version includes the supplied Mixkit tech-house music and laptop-keyboard recording, plus subtle clicks and transition sounds.
