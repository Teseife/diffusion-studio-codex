# Changelog

## 0.1.3 — October 3, 2026

Adds Claude Code installation from the public GitHub repository with a native marketplace catalog and plugin manifest. Codex and Claude Code use the same editing skill, HTTP MCP connection, and read-only diagnostic.

Includes a Claude Code guide for GitHub, local-clone and agent-assisted installation; the editing skill can be invoked as `/diffusion-studio:diffusion-edit`. Updates the shared guide for the now-public repository and adds automated package/install checks. The editor remains a local dependency; no hosted server is required.

## 0.1.2 — September 30, 2026

GitHub distribution candidate with a community marketplace, installation documentation, and an independent icon. The official Diffusion Studio logo used in the personal installation is excluded from this distribution.

Includes the local MCP connection, editing skill, and read-only diagnostic. This release requires local Codex execution and an installed Diffusion Studio app; it does not include a hosted editing service.
