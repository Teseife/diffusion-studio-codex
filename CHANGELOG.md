# Changelog

## 0.1.2 — September 30, 2026

GitHub distribution candidate with a community marketplace, installation documentation, and an independent icon. The official Diffusion Studio logo used in the personal installation is excluded from this distribution.

Includes the local MCP connection, editing skill, and read-only diagnostic. This release requires local Codex execution and an installed Diffusion Studio app; it does not include a hosted editing service.
